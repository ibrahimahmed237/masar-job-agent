# ADR-0011: Synchronous code

- **Status:** Accepted
- **Date:** 2026-11-13

## Context

Masar is a command-line tool for one person. Its slow parts are model calls, which run one after another inside a flow.

## Decision

All code is synchronous: `httpx.Client`, `sqlite3`, `graph.invoke`. The MCP server registers synchronous tools.

## Consequences

- **Good:** simpler code, simpler tests, simple stack traces.
- **Cost:** a long watchlist is assessed one posting at a time. Filters before the model keep the list short; parallel runs can be added behind the use case later.
